**MVC_CV**, kişisel özgeçmiş, yetenekler, deneyimler ve sertifikaların sergilendiği; ziyaretçilerin iletişim formu üzerinden mesaj gönderebildiği ve tüm içeriklerin dinamik bir **Admin Paneli** üzerinden yönetildiği full-stack bir **ASP.NET MVC** web uygulamasıdır.

---

## 📌 Proje Özellikleri ve Modüller

Proje, Katmanlı Mimari (N-Tier Architecture) prensiplerine uygun olarak geliştirilmiştir ve 2 ana bölümden oluşur:

### 🌐 Ziyaretçi Tarafı (Single Page CV / UI)
* **Hakkımda (About):** Kişisel bilgiler, unvan, profil fotoğrafı ve kısa biyo.
* **Deneyimlerim (Experience):** Geçmiş iş ve staj tecrübelerinin kronolojik olarak listelenmesi.
* **Eğitim Hayatım (Education):** Okul, bölüm ve derece bilgilerinin sergilenmesi.
* **Yeteneklerim (Skills):** Yetkinlik seviyeleri ve kullanılan teknolojilerin listesi.
* **Hobilerim (Interests):** İlgi alanları ve kişisel hobiler.
* **Sertifikalarım (Certificates):** Alınan sertifika, kurs ve başarı belgeleri.
* **İletişim (Contact Form):** Ziyaretçilerin doğrudan mesaj gönderebileceği dinamik iletişim formu.

### ⚙️ Yönetim Paneli (Admin Panel)
* **Kimlik Doğrulama (Authentication):** Yetkisiz erişimleri engelleyen güvenli Admin Login mekanizması.
* **Dinamik İçerik Yönetimi (CRUD):** Deneyim, eğitim, yetenek, hobi ve sertifikaların kolayca eklenip, güncellenip silinebilmesi.
* **Gelen Mesajlar Yönetimi:** İletişim formundan gelen mesajların okunması ve yönetilmesi.

---

## 🛠️ Mimari ve Teknolojiler

* **Backend:** C#, ASP.NET MVC 5
* **Mimari:** N-Tier Architecture (Business, Data Access, Entity, UI Layers)
* **ORM:** Entity Framework (Code First)
* **Veritabanı:** MS SQL Server
* **Frontend:** HTML5, CSS3, Bootstrap 4, JavaScript, jQuery
* **Tasarım Şablonu:** Start Bootstrap - Resume Theme / Custom Admin Template
